# Git Conflict

## Где возник конфликт
Конфликт возник в файле `project-notes.md` при слиянии ветки
`feature-tags` в ветку `main`.

Причина: в обеих ветках была изменена одна и та же строка —
`Backend: Python`. В `main` она была заменена на
`Бэкенд`, а в `feature-tags` — на `Java`.

## Как исправлен
1. Открыла файл `project-notes.md`.
2. Увидела маркеры `<<<<<<< HEAD`, `=======`, `>>>>>>> feature-tags`.
3. Вручную выбрала вариант `python` как итоговый.
4. Удалила маркеры конфликта.
5. Выполнила: `git add project-notes.md` `git commit -m "fix: разрешён конфликт выбора языка"`
6. Отправила изменения на GitHub через `git push`.
